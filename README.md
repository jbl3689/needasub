# NeedASub

**NeedASub** is an on‑demand football (soccer) marketplace that connects teams needing last‑minute substitutes with players looking to join a match. Think of it as "Uber for football": teams post match listings, players build profiles, and both sides can quickly find each other.

---

## 💡 What is this?

This project is a **prototype/web app** built with **Next.js (App Router)** that showcases how a football substitution marketplace can work:

- Teams can create listings for upcoming matches (location, match type, positions needed, etc.)
- Players can create profiles with availability, position, skill level, and location
- The home page is a marketplace where visitors browse **Players** and **Teams**
- Authentication is handled with **Supabase (email/password)**

> ⚠️ Note: Some UI pieces (like creating listings) are scaffolded as mock forms and may need backend wiring to fully persist data.

---

## 🧰 Tech Stack

- **Next.js 14 (App Router)**
- **React 18 + TypeScript**
- **Tailwind CSS** + **shadcn/ui** components
- **Supabase** (Auth + Database) using the official `@supabase/supabase-js` and `@supabase/ssr`
- UI icons: **lucide-react**
- Form validation: **react-hook-form** + **zod** (some parts)

## 🚀 Getting Started

### 1) Requirements

- Node.js (v18+ recommended)
- npm/yarn/pnpm
- A Supabase project (free tier works)

### 2) Clone the repo

```bash
git clone https://github.com/<your-org>/needasub.git
cd needasub
```

### 3) Install dependencies

```bash
npm install
```

### 4) Configure Supabase

Create a `.env.local` at the project root with:

```env
NEXT_PUBLIC_SUPABASE_URL=https://<your-project>.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=<your-anon-key>
```

> ✅ The repo includes a `.env.local` with demo values; be sure to replace them with your own and do NOT commit secrets.

### 5) Run the app

```bash
npm run dev
```

Open http://localhost:3000

## 🗂️ Database Schema (Supabase)

This project expects a Supabase **`public`** schema with the following tables (generated from the types in `src/lib/constants/types/supabaseTypes.ts`):

- `profiles`
- `player_profiles`
- `teams`
- `team_listings`
- `listing_applications`
- `team_members`
- `player_ratings`
- `team_ratings`

> Tip: Use the autogenerated TypeScript schema under `src/lib/constants/types/supabaseTypes.ts` as the source of truth for columns.

## 📁 Project Structure (High Level)

- `src/app/` — Next.js App Router pages (home, auth)
- `src/components/` — Reusable UI components (teams, players, dialogs, nav)
- `src/actions/` — Server actions for Supabase (fetch/create teams & profiles)
- `src/lib/` — Helpers (Supabase clients, mappings, utilities)
- `src/lib/constants/` — Shared types and mapping helpers

---

## 🔧 Tips for Contributors

- If you add new Supabase queries, add or update the corresponding TS types in `src/lib/constants/types/supabaseTypes.ts`.
- UI components live under `src/components/` and use shadcn/ui primitives.
- Authentication is managed via Supabase cookies + a Next.js middleware (`middleware.ts`).
